# Linux 服务器部署说明（4 核 4G 足够）

把「同事转发订舱邮件 → 服务器自动生成 7 份手续包 → 回信 zip + 校验报告」跑成常驻服务。

## 一、流程总览

```
同事公司邮箱 ──转发──> 您的邮箱（IMAP 可达，如 QQ/163/企业邮箱）
                          │
                          ▼  mail_daemon.py 常驻轮询（默认 60 秒）
              ┌───────────────────────────────┐
              │ 1. 取新邮件，剥出订舱邮件本体     │
              │    （内嵌 rfc822 / .eml 附件 /   │
              │     内联正文三种转发形态都支持）   │
              │ 2. 附件里「主单号+托书/运单副本   │
              │    .pdf」自动放进模板目录          │
              │ 3. 跑管线 G1-G6 闸门              │
              └──────────────┬────────────────┘
                 ┌───────────┼─────────────┐
              全过 ↓        缺信息 ↓        硬伤 ↓
           直接生成      回信补充页链接    回信异常说明
           回信 zip      （公网令牌页）    （需人工处理）
           +核对单      同事网页补齐提交
                        →自动生成→回信 zip
```

**同一主单再次转发 = 按最新邮件重新生成**（旧版自动存档到 `出货手续包/_存档/{主单}_{时间}/`），
应对"一封邮件不准、后期有更改"：同事改完直接再转发一次即可。

## 二、服务器准备

Ubuntu/Debian 为例（其他发行版换包管理器即可）：

```bash
# Python 依赖（邮件守护只用标准库，下面是管线依赖）
sudo apt update
sudo apt install -y python3-pip fonts-noto-cjk
pip3 install pymupdf python-docx openpyxl

# 建运行目录与用户
sudo useradd -m dsv
sudo mkdir -p /opt/dsv && sudo chown dsv:dsv /opt/dsv
```

字体说明：安检单品名需要宋体/类宋字体。已装 `fonts-noto-cjk` 会自动被识别；
追求和 Windows 版完全一致，可把 `C:\Windows\Fonts\simsun.ttc` 拷到
`templates/fonts/simsun.ttc`（识别优先级最高）。

## 三、上传文件

把本机整个 DSV 目录结构同步上去（约 33MB，以后只需更新代码和鉴定汇总 xlsx）：

```
/opt/dsv/
├── templates/                  ← 整个 templates 目录（公共模板、测试2 各主单模板、鉴定汇总 xlsx）
├── 出货手续包/                  ← 自动生成，空目录即可
└── waybill-workflow-skill/
    └── scripts/                ← 全部 .py + mail_config.ini
```

可用 scp / rsync，例如：

```bash
scp -r DSV/templates DSV/waybill-workflow-skill dsv@服务器IP:/opt/dsv/
```

## 四、配置邮箱与网络

1. **邮箱开 IMAP**：QQ 邮箱 → 设置 → 账号 → 开启 IMAP/SMTP 服务，生成**授权码**
   （163/126 同理；企业邮箱找 IT 要 IMAP/SMTP 地址和应用密码）。
2. 填配置：

```bash
cd /opt/dsv/waybill-workflow-skill/scripts
cp mail_config.ini.template mail_config.ini
nano mail_config.ini        # 填邮箱、授权码、public_base（改成你的公网 IP 和端口）
chmod 600 mail_config.ini   # 含授权码，限本人可读
```

3. **放行端口**：云服务商「安全组」+ 系统防火墙放行 `http_port`（默认 8080/TCP），
   同事浏览器才能打开补充页。公网 IP 直连时 `public_base = http://公网IP:8080`。
   （可选进阶：Nginx 反代 + HTTPS + 域名，public_base 填 https 域名。）

## 五、装成系统服务

```bash
sudo cp /opt/dsv/waybill-workflow-skill/server/dsv-mail.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now dsv-mail
journalctl -u dsv-mail -f    # 看日志：出现「[IMAP] 已连接…开始轮询」即成功
```

## 六、上线自测

1. 自己给自己邮箱转发一封历史订舱邮件（如测试2 里那封）；
2. 一分钟内应收到回信：主题「出货手续包已生成（2 个主单 × 7 份）」，附件 zip + 核对单 html；
3. 把同一封再转发一次 → 应再次收到回信，且服务器上 `出货手续包/_存档/` 多出旧版存档；
4. （可选）故意转发一封缺航班信息的邮件 → 应收到「需要补充 X 项信息」回信，
   点开链接补完提交 → 自动收到手续包回信。

## 七、新主单的托书/运单副本模板怎么给（也是发邮件）

每票新主单需要两份模板 PDF（品名栏空白的托书、运单副本），同事不用登服务器，**直接发邮箱**：

| 方式 | 操作 | 效果 |
|---|---|---|
| ① 随订舱邮件一起发（推荐） | 转发订舱邮件时，把两份模板 PDF 加进附件 | 一步到位：模板入库 + 手续包直接生成回信 |
| ② 单独发一封模板邮件 | 新建邮件只带两份模板 PDF 附件发到收件邮箱 | 回信确认「模板已入库」；若已有手续包在等这份模板，会自动生成并回信 |

附件要求：**文件名必须含主单号 + 「托书」或「运单副本」**，如 `176-61334567托书.pdf`、`176-61334567 运单副本.pdf`；同名重发会覆盖旧模板（模板更新也是这么操作）。

若订舱邮件先到、模板没到：会收到补充链接回信，其中缺模板项会提示「把 PDF 作为邮件附件发到本邮箱」；模板发过来后会自动生成回信，不用再点页面。

## 八、日常维护

| 场景 | 操作 |
|---|---|
| 新机型没证书 | 在服务器上更新 `templates/苹果手机-网站查询信息汇总.xlsx`（或用补充页手工填），无需重启 |
| 新主单没托书/运单副本模板 | 同事把模板 PDF 作为邮件附件发到收件邮箱（文件名含主单号+托书/运单副本，自动入库），见第七节 |
| 改代码后生效 | `sudo systemctl restart dsv-mail` |
| 查日志 | `journalctl -u dsv-mail -n 200` |
| 待补充任务 | 存于 `出货手续包/_daemon_jobs.json`，重启不丢链接 |

## 九、与 Windows 版的差异（已知且可接受）

- **危险品确认单测页数**：Windows 用 Word 实测页数，Linux 无 Word 时按保守估算选字号
  （偏小一档保证一页，不影响内容）。
- 生成时 MuPDF 读 simsun.ttc 会打印 `truncated loca table` 警告，属字体集合读取杂音，不影响结果。
- 服务器上不弹浏览器/不自动打开文件（`RUNPKG_NO_OPEN=1` 已在 service 里设好）。
