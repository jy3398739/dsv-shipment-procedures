# 服务器交接说明（给负责部署的 AI / 运维）

> 这份包从开发机（Windows）原样导出，目标是部署成常驻服务：
> **同事转发订舱邮件 → 本服务器自动生成 7 份出货手续包 → 回信 zip + 校验报告**。
> 详细步骤见 `waybill-workflow-skill/server/部署说明.md`，本文件是交接总纲与验收标准。

## 一、这个项目是什么

电池货（苹果手机）国际空运的出货手续包自动化工具。输入一封订舱邮件，输出每个主单 7 份文件：
运单副本、安检单、应急措施、托运人声明(docx)、托书、交运单(xlsx)、危险品确认单(docx)。

核心链路（脚本在 `waybill-workflow-skill/scripts/`）：
```
邮件解析(booking_to_waybill.py) → G1-G6 六道闸门校验(run_package.py)
→ 原位编辑模板生成(gen_procedures.py) → 生成后文本层逐项校验
```
数据源：订舱邮件 + `templates/苹果手机-网站查询信息汇总.xlsx`（鉴定证书库，55+ 条）。

## 三、部署步骤（摘要，细节看 部署说明.md）

1. 解压到 `/opt/dsv/`，属主建议非 root 用户（如 dsv）。
2. 依赖：`apt install python3-pip fonts-noto-cjk`；`pip3 install pymupdf python-docx openpyxl`。
3. `cd waybill-workflow-skill/scripts && cp mail_config.ini.template mail_config.ini`，
   填入（这些值需要向服务器主人要，包里不含）：
   - IMAP/SMTP 主机与端口（QQ：imap.qq.com/smtp.qq.com，163 同理）
   - 邮箱账号 + **授权码**（不是登录密码）
   - `public_base = http://本机公网IP:8080`（有域名+HTTPS 则填域名）
   填完 `chmod 600 mail_config.ini`。
4. 防火墙/安全组放行 `http_port`（默认 8080/TCP）。
5. `cp server/dsv-mail.service /etc/systemd/system/`（核对里面 WorkingDirectory 路径），
   `systemctl daemon-reload && systemctl enable --now dsv-mail`。
6. `journalctl -u dsv-mail -f` 看到「[IMAP] 已连接…开始轮询」即启动成功。

## 四、验收标准（部署后自测）

1. 向收件邮箱转发任意一封含「件数 计费 毛重」表格的订舱邮件 → 1 分钟内回信
   「出货手续包已生成（N 个主单 × 7 份）」，附件 zip 解压后每主单 7 个文件。
2. 同封再转发一次 → 再次回信，且 `出货手续包/_存档/` 多出旧版目录（重复转发=覆盖重生成）。
3. 发一封只带模板 PDF 的邮件（文件名如 `176-61333915托书.pdf`）→ 回信「模板已收到并入库」。
4. （可选）发一封缺航班信息的订舱邮件 → 回信补充链接，浏览器打开能显示红框表单页。

## 五、必须知道的约定（排障关键）

- **中文目录/文件名是设计的一部分**（公共模板、测试2、出货手续包、托书.pdf 等），系统 locale 需 UTF-8（service 里已设 PYTHONIOENCODING）。
- 安检单品名用宋体：优先 `C:/Windows/Fonts/simsun.ttc`（本机无）→ `templates/fonts/simsun.ttc` → 思源宋体/文泉驿（`song_font()` 按序探测）。装了 fonts-noto-cjk 即可，无需额外操作。
- Linux 没有 Word：危险品确认单按保守估算选字号（保证一页，字号可能偏小一档），属预期行为。
- MuPDF 打印 `truncated loca table` 是读字体集合的杂音，不影响结果。
- 模板文件名规则：含 `176-\d{8}` 主单号 + 「托书/运单副本」才会被自动入库。
- 状态文件都在 `出货手续包/` 下：`_daemon_state.json`（已处理邮件 UID）、`_daemon_jobs.json`（待补充任务，重启不丢链接）、`_存档/`（重生成旧版）。
- 安全：`mail_config.ini` 含授权码，权限 600；补充页链接为随机令牌（/t/{token}/），公网直连 HTTP，如需更高安全级别可加 Nginx + HTTPS。

## 六、日常维护速查

| 场景 | 操作 |
|---|---|
| 新机型没证书 | 更新 `templates/苹果手机-网站查询信息汇总.xlsx`（无需重启） |
| 新主单模板 | 用户把 PDF 附件发到收件邮箱即自动入库（无需运维介入） |
| 改代码生效 | `systemctl restart dsv-mail` |
| 查日志 | `journalctl -u dsv-mail -n 200` |
| 磁盘增长 | `出货手续包/_存档/` 与 `_mails/` 可定期清理，其余勿动 |

## 七、开发机侧备注（背景信息）

- 开发机 Windows 版仍保留交互式三段流程（补充页→人工核对单→生成），服务器版是其无头化分支：
  `run_package.run_headless()` 为无头入口；服务器模式**没有人工确认环节**（闸门全过即生成），
  质量由 G1-G6 闸门 + 生成后逐项文本层校验兜底，校验不过会在回信里红色标注。
- 已知差异：危险品确认单测页数（见上）、生成速度每主单约 10-20 秒。
- 4 核 4G 余量充足（单票峰值约 200MB 内存）。
